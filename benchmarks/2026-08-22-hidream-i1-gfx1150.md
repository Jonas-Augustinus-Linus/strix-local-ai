# HiDream-I1 = gfx1150에서 작동하는 무검열 정밀 이미지 모델 (2026-08-22)

## 요약 (TL;DR)

Qwen-Image가 gfx1150에서 DiT 행으로 실패한 자리를 **HiDream-I1 Fast가 해결**했다.
무검열 abliterated Llama 인코더 + 진짜 네거티브로 **SFW 한복·동아시아 인물을 정확히** 생성한다
(FLUX-abliterated가 원리적으로 못 하던 것). 아시아 인물 30장 배치 완주, 전부 고품질.

**단, gfx1150 ROCm 웨지 주의**: 연속 부하 ~6-8장(가변)에서 GPU가 웨지되어 이후 DiT 샘플링이
전부 행. **ComfyUI 재시작으로 해제됨(재부팅 불필요)** — firmware MES 웨지(#5993, 재부팅 필요)와 다름.
→ **청크 실행**(세션당 1-3장 후 ComfyUI 재시작)으로 대량 배치 완주 가능.

## 작동 레시피 (검증됨)

- **DiT**: `city96/HiDream-I1-Fast-gguf` → hidream-i1-fast-Q5_K_M.gguf (13G). Fast=16step cfg1(distilled). Full/Dev도 있음(고품질, 느림).
- **인코더 4개 (QuadrupleCLIPLoaderGGUF)**:
  - clip_l_hidream.safetensors + clip_g_hidream.safetensors (Comfy-Org/HiDream-I1_ComfyUI)
  - **t5xxl-Q5_K_M.gguf** (city96/t5-v1_1-xxl-encoder-gguf) — **GGUF 필수**
  - **llama-3.1-8b-abliterated-Q6_K.gguf** (mlabonne) — **무검열 인코더(핵심)**
- **VAE**: hidream-ae.safetensors (Comfy-Org, =flux ae 16ch). **bf16-vae OK** (Qwen과 달리 fp32 불필요).
- **워크플로**: UnetLoaderGGUF → ModelSamplingSD3(shift 3.0) → QuadrupleCLIPLoaderGGUF(clip_l,clip_g,t5-gguf,llama-gguf; **type 파라미터 없음**) → CLIPTextEncode(pos+진짜 neg) → KSampler(euler/normal, 16step, cfg 1.0) → VAEDecode → SaveImage.
- **ComfyUI 플래그**: `--gpu-only`(인코더 GPU 필수, 아니면 CPU 스테이징 30분) + `--disable-mmap --cache-none --bf16-vae --reserve-vram 2`. split-attention 무관(HiDream은 안 걸림).

## 두 개의 함정 (해결됨)

1. **"Mixing scaled FP8 with GGUF is not supported"** — 재사용하던 t5xxl_fp8_scaled(safetensors)를 GGUF llama와 같은 QuadrupleCLIPLoaderGGUF에 넣으면 에러. → **GGUF t5 사용**.
2. **인코더 CPU 병목** — DynamicVRAM이 8B Llama 인코더를 CPU 스테이징 → 인코딩 30분. → **`--gpu-only`** 로 GPU 강제.

## 성능 (890M, Fast Q5, 1024² batch 2, 16step)

- 장당(2장) ~650-680초 (~11분). 한 장 환산 ~5.5분.
- **웨지 임계**: 세션(ComfyUI 인스턴스)당 대략 3-7런 후 웨지 (가변, 열/누적 추정). 1런/세션은 절대 안 걸림(웨지체크 641s OK).
- **대량 배치 패턴**: 세션당 3런(6장) 이하로 청크 + 청크마다 ComfyUI 재시작. 안전하게는 1런/세션.

## 결론

- **무검열 + 정밀제어(네거티브) + 아시아/한복** = HiDream-I1이 이 박스의 답. (FLUX=실사 예술·서구편향, SDXL=애니, HiDream=무검열 정밀 실사·아시아.)
- 배치 스크립트는 **post/get 방어 + hang→skip**(개별 스톨이 배치를 죽이지 않게) 필수 — 초기 스크립트가 미방어 interrupt로 크래시했음(수정 완료).
