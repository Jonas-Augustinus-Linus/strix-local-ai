# Huihui-Qwen3.6-35B-A3B-abliterated KO-i1 한국어 KLD (2026-08-19, 4차 릴리스)

**질문**: abliteration(거부 학습 제거)이 한국어 imatrix 보정의 효과에 영향을 주는가?
**답**: **거의 무영향.** abliterated 모델의 KLD 사다리는 정식판과 실질 동일 —
양자화 견고성은 abliteration과 무관하다.

## 방법론
- 기준: abliterated **f16**(66.2G, huihui safetensors → convert)의 로짓, `-c 512`
- 코퍼스·방법론 전부 2차(정식 Qwen3.6 KO-i1)와 동일 → 직접 비교 가능
- 전 단계 CPU 빌드 (G6), MTP blk.40 q4_K 고정 (dry-run 확정, G7)
- imatrix 708청크 최종 PPL 8.375 (정식 8.44보다 근소히 낮음 — abliterated가 살짝 더 매끄러움)
